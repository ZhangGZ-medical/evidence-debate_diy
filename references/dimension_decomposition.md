## 检索结果合并与去重

### 合并策略

1. 每个维度独立检索，保存为 `{维度}_list.txt`
2. 用 Python 脚本合并所有清单，按 PMID 去重
3. 记录每条文献的**维度归属**（一条文献可能属于多个维度）

### 去重脚本

```python
import json, glob

all_records = {}
for f in glob.glob('*_list.txt'):
    dim = f.replace('_list.txt','')
    for line in open(f, encoding='utf-8'):
        parts = line.strip().split('|')
        if len(parts) >= 4:
            pmid = parts[0]
            if pmid not in all_records:
                all_records[pmid] = {
                    'pmid': pmid, 'year': parts[1], 'journal': parts[2],
                    'title': parts[3], 'dimensions': [dim]
                }
            else:
                all_records[pmid]['dimensions'].append(dim)

print(f'去重后总数: {len(all_records)}')

# 按维度统计
for dim in ['IA_NSC_stroke','IC_NSC_chronic','FMMS_placebo','DTI_CST','homing','synaptic','exosome','cochrane']:
    n = sum(1 for r in all_records.values() if dim in r['dimensions'])
    print(f'  {dim}: {n}')

# 保存
with open('all_records.json','w',encoding='utf-8') as f:
    json.dump(list(all_records.values()), f, ensure_ascii=False, indent=1)
```
