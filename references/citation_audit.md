# 引用回溯核查（Citation Back-Audit）

> **本文件记录的是一次真实事故的教训。**
> 在某细胞治疗项目（40 轮攻防、180 条候选文献）完成后，对正文引用的 17 篇一手文献做逐篇精读核查，
> 结论是：**17 篇中，无一篇的引用是完全准确的。**
> 更严重的是，两条支撑最终判决的核心结论，其依据的数据**在原始文献中根本不存在**。
> 若该报告直接交付投资人或监管方，任何认真核查的人都能推翻它。

---

## 一、为什么必须做回溯核查

调研类任务的失效模式，通常不在"没找到文献"，而在**找到了文献但没有真读**。

三个结构性原因：

1. **摘要与全文的信息密度差异巨大**。关键限定语（`may`、`not solely`、`suggesting`）、
   研究设计（横断面 vs 纵向、假手术 vs 疾病模型）、统计量的性质（WMD vs 组内变化）
   往往只在全文的方法或讨论部分出现。
2. **grep/片段检索制造虚假确信**。检索命中一段话，会让人误以为掌握了该文献的立场，
   而实际上同一篇文献的其他章节可能载有**方向相反**的证据。
3. **转引会逐层失真**。综述引用 A 研究，我们引用综述，若不回溯到 A，
   就会把"小鼠静脉注射"的结论当作"人体动脉给药"的证据。

---

## 二、核查时机

**在攻防完成、判决形成之后，交付之前。** 这是最后一个关口。

不要等到有人质疑才核查——那时成本已经是重写。

---

## 三、核查范围

对**正文实际引用的每一条**逐一核查。注意：
- 不是核查全部候选文献（成本过高），而是核查**真正被写进论证链**的那些
- 引用编号重复的同篇（如 [1]=[13]）合并核查
- 内部文件、注册库数据不在此列，但注册库数据应核对 `resultsSection` 原始值

> **⚠️ v3 补充（全库精读教训）**：
> ① **补充参考文献清单（分组条目如 [A8]/[C9]/[F25]）同样需要核查**——本次事故中，清单条目的
>   标题改写（失语症→卒中恢复）、细胞类型归属错误（MSC→NSC）、跨物种遗漏（删 "Porcine"）全部发生在
>   分组清单里，而非正文引用里；
> ② **N 值必须精确到"发表分析数 vs 登记入组数"**——NSI-566 的 N=9 是已发表分析数，登记为 18；
> ③ **时相定义必须核对**——同一研究可能被不同综述归入不同时期（PISCES-II 入组 2–3 个月，
>   被当作"慢性期"证据存在时相错配）；
> ④ 若证据库规模允许（≤150 篇），建议升级为**全库精读**（见 `full_library_reading.md`），
>   只精读引用的文献无法发现"引用错误的文献本身有问题"。

## 四、必查错误（v3 扩充为五类）

### 类型 ①：数据不存在

**症状**：报告写"文献 X 显示 Y"，但全文检索 Y 相关关键词 **0 命中**。

**高危场景**：
- 把 A 文献的数字记成了 B 文献的（**跨文献归属错误**）——这是本次事故中最常见的一类
- 把报告自己计算的换算值（如 66 分制折算 100 分制）当成了文献数据
- 把记忆中的领域常识当成了当前文献的发现

**核查方法**：对每一个引用数值，在全文文本中检索其数字本身与同义表述。
若 0 命中，立即标记为「数据不存在」，并尝试在**其他**已下载文献中定位其真实出处。

### 类型 ①b：引语不存在（v3 新增，最隐蔽）

**症状**：结论方向正确、文献也正确，但**引用的英文原句在全文 0 命中**。

**实例**：报告引 PMC12866691 的"scar and ECM formation limit integration"——
该句全文 0 命中；原文实际表述是 "scarring and tissue loss are more advanced, making regeneration less likely"。
结论方向一致，**但引语是编造的**（或从记忆中错误拼接）。

**核查方法**：**每一个带引号的英文引语，必须 grep 全文逐字确认存在**。
不能只核对"结论方向对"就放过。这是五类错误中最隐蔽、也最容易被同行当场揭穿的一类。

### 类型 ②：跨外推未标注

**症状**：数字属实，但其产生条件与使用场景不匹配。

**四个必须核对的维度**：

| 维度 | 需核对 |
|---|---|
| **物种** | 人 / 非人灵长类 / 大动物 / 啮齿类 / 体外 |
| **模型** | 疾病模型 / **假手术（sham）模型** / 正常动物 |
| **给药途径** | 静脉 / 动脉 / 脑内 / 鞘内 / 鼻内 |
| **适应症** | 研究实际疾病是否等于论证所涉疾病 |

**本次事故的典型**：一篇被广泛引用为"MCAO 大鼠模型安全剂量"的研究，
实为 **sham-MCAO 假手术大鼠**，作者在局限性中明确写道"不能排除缺血状态下细胞行为不同"。

### 类型 ③：统计量 / 时期错配

**症状**：数值属实，但**统计量的性质或所指时期被误读**。

**高发错误**：

| 误读 | 真相 |
|---|---|
| 把 **WMD/SMD（组间差）** 当作某一组的改善量 | WMD 是"实验组改善 − 对照组改善" |
| 把 **SMD（标准化均数差）** 当作量表原始分值 | SMD 无量纲，不能与 FMA 分值并列 |
| 把**某一时期亚组**的数值当作另一时期的 | 急性期 vs 亚急性期 vs 慢性期必须逐一对应 |
| 把**组内前后变化**当作**安慰效应** | 组内变化混杂自然恢复、回归均值、合并干预 |
| 把**登记入组数**当作**发表分析数**（v3） | NSI-566 登记 18 vs 发表分析 9 |
| 把**随访时长**当作**时间窗**（v3） | 某些荟萃的 6/12/24 月是随访时长，非卒中分期 |

### 类型 ④：原文限定语被删除

**症状**：把原文的推测、保留或并列关系，改写成确定、排他或单因。

**高危措辞清单**（出现即须逐字核对原文）：

| 原文 | 常见误写 | 性质变化 |
|---|---|---|
| `not solely A but also B` | 不依赖于 A（仅为 B） | 并列 → 排他 |
| `may shift over time` | 随时间转换 | 推测 → 结论 |
| `As the environment stabilizes...` | 在慢性期 | 条件句 → 时期断言 |
| `no evidence of X` | 无 X / X 不存在 | 未检出 → 证伪 |
| `we suggest / might` | 结论是 | 推测 → 定论 |
| `significant number`（定性） | 入脑率 X% | 定性 → 定量 |

### 类型 ⑤：负面证据遗漏与"类别级"过度概括（v3 新增）

**症状 a（遗漏）**：文献载有**与论证方向相反**的数据，但报告未引用。
**处理**：精读时必须主动寻找并优先补入。本次事故通过此路径补入了 IA 亚组荟萃阴性、
hNSC 不入脑、外泌体双向性等改变判决的证据。

**症状 b（类别级概括）**：把"特定条件下成立"的结论推广为"类别属性"。
**实例**：① 外泌体"机制自洽"——原文实为"特定来源+特定货物+特定模型"的自洽，
且外泌体有**双向性**（给外源 EV 获益 vs 抑制内源 EV 释放亦获益）；
② 外泌体"安全性最高"——荟萃 38 项动物研究**零 AE 报告 ≠ 零 AE**。
**处理**：任何"X 类别整体上 Y"的表述，须检查原文是否限定为"特定条件下"。

## 五、核查产出格式

每篇输出一个文件，八节结构（模板见 `paper_reading_protocol.md`），
其中**第 7 节「引用核查」是核心**，逐条给出判定：

| # | 报告表述 | 原文事实（含英文原句与章节） | 判定 |
|---|---|---|---|
| 1 | "...[n]" | 原文："......"（章节：3.1.2） | ✅ / 🟠 / 🔴 |

**判定标准**：
- ✅ **准确**：数值与定性均与原文一致，未跨适应症/跨物种/跨途径外推
- 🟠 **部分偏差**：数值对但表述有偏差，或遗漏了限定条件
- 🔴 **错误**：数据不存在 / 方向相反 / 归属错误 / 跨适应症误用

**第 8 节「本文未提供的数据（负面清单）」同等重要**——
显式列出"可能会被误引但本文实际没有"的数据，防止后续二次误引。

## 六、核查后的处置

### 1. 撤回而非修补

凡经核查证伪的表述，**无论其结论对哪一方有利，一律更正**，并在正文保留修订痕迹：

```markdown
> **⚠️ v2 修正**：v1 此处写作"..."。精读确认：原文为"..."。
> 修正后论证依据变化，但结论方向不变（且因补充了...而更强）。
```

**不要悄悄改掉**。保留痕迹既是诚信要求，也让读者了解决议的演化。

### 2. 重新评估判决

撤回关键论据后，**必须重跑攻防**，不能只做局部修补。
本次事故中，两条核心结论被撤回后，两条管线的概率均下调了 5–10 个百分点，
资源分配建议也随之改变。

### 3. 主动寻找"被遗漏的反向证据"

核查时若发现某篇文献载有**与本项目主张相反**的数据，
且该数据在原报告中未被引用，必须**优先补入**。
本次事故即通过此路径补入了两条改变判决的关键证据。

## 七、七条铁律（核查清单）

完成核查前，逐条自问：

- [ ] 1. 叙述性综述的**定性优势描述**是否被反向引用成了数字？
- [ ] 2. 是否把**组内前后变化**当成了安慰效应？（安慰效应须为"假 − 未治疗"或"真 − 假"的组间差）
- [ ] 3. 引用的 WMD/SMD 是否被当成了某一组的改善量？
- [ ] 4. 亚组数值正确，是否就断言了**亚组间比较**成立？（须查 CI 是否重叠、有无交互检验）
- [ ] 5. **转引数据**是否回溯到了原始研究？（物种 / 途径 / 时点）
- [ ] 6. 动物模型是否确认为**疾病模型**而非假手术模型？
- [ ] 7. 原文的**限定语**（may / not solely / suggesting）是否被删除？

---

## 八、成本提示

本次核查 17 篇，产出 44.6 万字，耗时约 3.5 小时（6 个 Agent 并行）。

**这个成本必须花。** 因为核查发现的问题不是"可以更精确"，而是"结论不成立"。
一份引用不可核查的尽调报告，其危害大于没有报告——它会给出虚假的确定性。
